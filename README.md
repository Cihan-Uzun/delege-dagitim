# Delege Dağıtım ve Birleştirme

Mobil uyumlu tek sayfa. `index.html` dosyasını açın veya GitHub Pages / Vercel ile yayınlayın.

## Kullanım
1. Hedef delege sayısını girin.
2. Excel/CSV yükleyin veya listeyi yapıştırın.
3. Kolonlar: SGK No, İşyeri Unvan, Kategori, İl, İlçe, Üye.
4. Dağıt ve birleştir → Excel indir.

Uşak örneği uygulamada hazır gelir (1.147 üye / 60 delege).
